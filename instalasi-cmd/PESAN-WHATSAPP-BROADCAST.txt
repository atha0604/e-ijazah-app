📥 CARA INSTALL (3 LANGKAH)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ LANGKAH 1: Install Node.js (Sekali saja)
👉 https://nodejs.org/
- Download versi LTS
- Install → Next → Next → Finish
- Restart komputer

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ LANGKAH 2: Download Aplikasi

🔷 CARA A - OTOMATIS (Recommended)

1. Tekan Windows + R
2. Ketik: cmd
3. Enter
4. Copy-paste perintah ini:

powershell -Command "cd C:\; Invoke-WebRequest -Uri 'https://github.com/atha0604/e-ijazah-app/archive/refs/heads/brave-black.zip' -OutFile 'e-ijazah.zip'; Expand-Archive 'e-ijazah.zip' 'C:\E-Ijazah' -Force; cd 'C:\E-Ijazah\e-ijazah-app-brave-black'; npm install"

5. Enter dan tunggu 5-10 menit

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔷 CARA B - MANUAL (Jika Cara A gagal)

1. Buka: https://github.com/atha0604/e-ijazah-app
2. Klik tombol hijau "Code"
3. Klik "Download ZIP"
4. Extract ke C:\E-Ijazah\
5. Buka folder hasil extract
6. Double-click: INSTALL-SEKOLAH.bat

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ LANGKAH 3: Jalankan Aplikasi

1. Buka folder: C:\E-Ijazah\e-ijazah-app-brave-black\
2. Double-click: JALANKAN-APLIKASI.bat
3. Browser akan terbuka otomatis
4. Login dengan kode sekolah (dikirim terpisah)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
