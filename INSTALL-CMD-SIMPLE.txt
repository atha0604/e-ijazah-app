🔷 CARA 1: ONE-LINER SUPER CEPAT (RECOMMENDED) ⭐

🔷 CARA 2: DOWNLOAD SCRIPT INSTALLER DULU

Step 1 - Download installer:
powershell -Command "Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/atha0604/e-ijazah-app/brave-black/INSTALLER-OTOMATIS-LENGKAP.bat' -OutFile '%USERPROFILE%\Desktop\INSTALL-EIJAZAH.bat'"

Step 2 - Jalankan installer:
(Double-click file INSTALL-EIJAZAH.bat yang ada di Desktop)

🔷 CARA 3: DOWNLOAD DARI GITHUB ZIP

1. Buka browser, kunjungi:
   https://github.com/atha0604/e-ijazah-app

2. Klik tombol hijau "Code"

3. Klik "Download ZIP"

4. Extract ZIP ke: C:\E-Ijazah\

5. Buka folder, jalankan: INSTALLER-OTOMATIS-LENGKAP.bat

❓ TROUBLESHOOTING

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "PowerShell execution policy error"

Solusi:
powershell -ExecutionPolicy Bypass -Command "perintah anda"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Cannot download - network error"

Solusi:
1. Cek koneksi internet
2. Disable antivirus sementara
3. Gunakan Cara 3 (Download ZIP manual)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Node.js installed but not found"

Solusi:
1. Restart komputer
2. Jalankan installer lagi

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Port 3000 already in use"

Solusi:
npx kill-port 3000

Atau restart komputer
